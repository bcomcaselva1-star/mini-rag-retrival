# Mini RAG Retrieval System

## About
A beginner-friendly Python project that demonstrates
basic information retrieval using keyword matching.

## Features
- Searches a small knowledge base
- Matches question keywords with stored documents
- Displays relevant information
- Runs directly in the terminal

## Technologies
- Python 3
- String processing
- Sets and sorting
- Basic information retrieval

## How to Run
1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

   python main.py

## Example
Question: What is RAG?

Output:
- RAG stands for Retrieval-Augmented Generation.
